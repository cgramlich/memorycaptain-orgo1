# MemoryCaptain — Organic Chemistry 1

A spaced-repetition study deck: 879 cards covering chapters 1–12 of first-semester
organic chemistry, each citing the section and printed page it was drawn from.

Open it here: **https://cgramlich.github.io/memorycaptain-orgo1/**

Your progress is saved in your browser (nothing leaves your device), so use the
same browser each session. Answer in your own words, check yourself, and rate
how it went — the scheduler decides when you see each card again, at stretching
intervals as you get them right.
